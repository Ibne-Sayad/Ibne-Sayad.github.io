# Professional Experience tool icons

Retrieved 2026-11-12 from official vendor/project sources. Local images identify tools beside unchanged text labels; no endorsement is implied. All marks belong to their respective owners. No artwork was generated, traced, recolored, or cropped. SVG originals are unchanged; raster icons were resized proportionally to at most 48 x 48 and losslessly PNG-compressed. Images are decorative to screen readers because each badge already contains the tool name.

## Scope

Only existing software tool badges receive icons. Android, iOS, Web, Accessibility, UAT, Regression Testing, Rollout Coordination, REST API, Performance Testing, CMS, E-commerce, and Integration Testing remain text-only. Git, Jenkins, Docker, Playwright, Cypress, Selenium, and BrowserStack are not added because they are not existing badges in these roles. All nine used tool identities were verified; no fallback or invented icon was required.
